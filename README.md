Porting native Android dari **Hero Of Sparta** (`GloftSPAW`, Sony Ericsson X1i `480×800` Portrait) lengkap dengan **Immersive Fullscreen** (tanpa black bar), **Floating HUD Cheat & Opsi**, dan kontrol sentuh penuh! 🛡️🔥🏛️

---

## ✨ Fitur Utama
- 📱 **Immersive Fullscreen Portrait (`480×800`)**: Tampilan penuh tanpa black bar dengan pilihan **Layar Penuh (Stretch)** atau **Aspek Asli (`480×800`)**.
- 👆 **Sentuhan Penuh**: Mendukung `pointerPressed`, `pointerDragged`, dan `pointerReleased` langsung di layar game.
- ⚡ **Tombol Cheat (`⚡ CHEAT` di Kiri Atas)**:
  - Akses cepat tombol **Cheat/Debug (`*`)**, **Unlock/Bonus (`#`)**, **Serang (`FIRE`)**, serta Softkey `LSK`/`RSK`.
- ⚙️ **Tombol Opsi (`⚙ OPSI` di Kanan Atas / Tombol Back)**:
  - 📐 Mode Layar (**Layar Penuh Stretch** / **Aspek Asli `480×800`**)
  - 🎯 Pengaturan **FPS** (`15 / 20 / 25 / 30 FPS`)
  - 📳 Toggle getar tombol (`ON / OFF`)
  - 🚪 Keluar Game
